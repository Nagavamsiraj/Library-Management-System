
# 📚 Library Management System

A SQL-based Library Management System built using MySQL Workbench to manage books, members, and borrowing records efficiently.

This project focuses on creating a structured relational database with real-world library operations such as issuing books, tracking returns, and managing records using SQL queries.

---

## 🚀 Features

* Manage library books and categories
* Store member details
* Track issued and returned books
* Fine management system
* SQL filtering and search queries
* JOIN operations between tables
* COUNT queries for reports and statistics

---

## 🛠 Technologies Used

* MySQL
* MySQL Workbench
* SQL

---

## 🗂 Database Tables

  📖 Books

      Stores information about all books available in the library.

  👤 Members

      Stores member registration details.

  🔄 Issued_Books

      Maintains borrowing and return records.

---

## 🔍 SQL Operations Included

  * Database Creation
  * Table Creation
  * Data Insertion
  * SELECT Queries
  * WHERE Conditions
  * JOIN Queries
  * COUNT Queries
  * Foreign Key Relationships

---

## ▶ How to Run

  1. Open MySQL Workbench

  2. Open " library_management_system.sql "

  3. Run the complete script using :

      " Ctrl + Shift + Enter "
